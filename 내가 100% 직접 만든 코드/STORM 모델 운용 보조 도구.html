구성 성분 ListUp 설정

◉ ID:를 포함하는 줄에서 발견되는 큰따옴표로 된 문구들을 모아오는 기능이다.
◉ 수행 범위 시작 및 종료 줄 지정 = 사용자가 지정한 파일에서 가장 먼저 등장하는 시작 문구 줄부터 가장 먼저 등장하는 끝 문구 줄까지만 다룬다.
◉ 삭제 구간 시작 및 종료 키워드 = 위에서 지정한 범위 안에서 제외 시작 문구 줄부터 제외 끝 문구 줄까지는 제외시킨다는 것이며 조건이 맞는 영역이 여러 개 발견되면 위와 달리 중복 적용된다.
◉ 특정 문구 키워드 = ID:를 찾았을 때, 그것과 아래 방향으로 가장 가까운 이 문구를 찾아서 그 안에 있는 ID: 옆 큰따옴표로 된 문구들을 모아온다.
◉ 입력 예시 : typeaa.dat을 대상으로, 각각 Begin Type_Air_Asset / End Type_Air_Asset / CAP_Flight_Coverage / End Asset_ISR_Sensor_List / Configuration_List를 순서대로 입력


ID ListUp 생성

◉ ID:를 포함하는 줄에서 발견되는 큰따옴표로 된 문구들을 모아오는 기능이다.
◉ 수행 범위 시작 및 종료 줄 지정 = 사용자가 지정한 파일에서 가장 먼저 등장하는 시작 문구 줄부터 가장 먼저 등장하는 끝 문구 줄까지만 다룬다.
◉ 해당 기능은 grdunit.dat, surfacetarget.dat 등에서 사용할 수 있다.


Twin ListUp

◉ A와 B 문구를 입력하면 각 문구가 발견되는 줄에 존재하는 값들을 모아오는 기능이다.
◉ 수행 범위 시작 및 종료 줄 지정 = 사용자가 지정한 파일에서 가장 먼저 등장하는 시작 문구 줄부터 가장 먼저 등장하는 끝 문구 줄까지만 다룬다.
◉ 해당 기능을 grdunit.dat으로 예시를 들면, A와 B에 각각 ID:와 Superior_Command:를 입력하여 각 ID별로 Command 값만을 모아 확인할 수 있게 한다.
